# Dopamine Detox Tracker

Повноцінний full-stack трекер продуктивності та цифрового детоксу, який аналізує активність користувача за комп'ютером, виявляє простій та виводить мотиваційні сповіщення при перевищенні лімітів часу у відволікаючих програмах.

## Стек технологій
* **Backend:** .NET 10 (C#) Web API, Entity Framework Core, PostgreSQL (або SQLite).
* **Frontend:** React, Vite, TypeScript, Recharts (для візуалізації графіків).
* **Desktop Agent:** C# Фоновий сервіс, Win32 API (`user32.dll`), Microsoft.Toolkit.Uwp.Notifications (для нативних Windows сповіщень).

## Архітектура та можливості
1. **Desktop Agent:** Відстежує активне вікно, ігнорує бездіяльність (понад 60 секунд) та пакетно відправляє телеметрію на сервер. Виводить системні сповіщення Windows при перевищенні ліміту.
2. **REST API:** Приймає пакети телеметрії, зберігає в БД та агрегує статистику (денну та тижневу).
3. **React Client:** Дашборд із поточними метриками дня та тижневими трендами.

## Як запустити проєкт (Швидкий старт)
Для запуску всіх компонентів одночасно розроблено автоматизований скрипт.
1. Відкрийте кореневу папку проєкту.
2. Запустіть файл `start.bat`.
3. Скрипт автоматично відкриє три термінали та запустить API, Фоновий агент і React-дашборд у браузері.

## Тестування
Проєкт покритий юніт-тестами (xUnit + In-Memory DB). Для перевірки виконайте команду в корені:
`dotnet test`
